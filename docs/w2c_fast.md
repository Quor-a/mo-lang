# 反编译 → 结构化快速推理（1.91）

## 一句话

1.90 证明了「结构化乘比先展开再乘快 307x」，但部署场景的真实对手是
**已经物化好的稠密矩阵**。换成这个对手重测，结论要收着说 —— 而且顺带
量出一个此前没人量过的权衡：**拟合最好的基，未必是跑得最快的基。**

## 核心发现：无约束反编译会选出「跑不动」的基

同一张训好的 32×32 权重，K=8，两种约束：

| 约束 | 残差 | 选中的 O(n²) 基 | 256 样本推理一轮 |
|---|---|---|---|
| 无约束（谁拟合得好选谁） | 63627 | **1** | **5737 µs** |
| 只允许可分离 | 62223 | **0** | **1751 µs** |
| 稠密（已物化 1024 个数） | — | — | 1127 µs |

**无约束版本比稠密慢 5 倍。** 原因：贪心 OMP 按「残差下降量」选基，
`HASH`（伪随机高频）下降得最快，但它是 O(n²) 且必须逐点求值 ——
拟合质量换来了不可用的推理速度。

**而把它排除掉，残差反而略微变好**（63627 → 62223）。
贪心 OMP 不保证最优，限制候选池有时能避开局部陷阱。

于是有了 `w2c_fit_sep(K)`：只允许可分离（O(n)）基的反编译入口。

## 诚实的加速比

1.90 报的 307x 是「vs 先展开 n² 再乘」。部署场景的真实对手是
**已经物化好的稠密矩阵**：

| n | 权重数 | 稠密 matvec | 结构化（8 基） | 存储比 |
|---|---|---|---|---|
| 32 | 1024 | 4138 ns | 4023 ns | 32x |
| 64 | 4096 | 14531 ns | 8024 ns | 128x |
| 128 | 16384 | 56429 ns | **15869 ns** | **512x** |

- **小层（n=32）是平手** —— 每个基的函数调用开销吃掉了复杂度的优势
- **n≥64 结构化开始领先**，n=128 时 3.6x，且差距随 n 线性拉开
- **存储比始终成立**：n=128 时 16384 个数 → 32 个数 = 512x

所以结构化推理的收益是**大层 + 内存受限**场景，不是万能加速。

## 正确性隔离

实测里「反编译后与原网络的预测翻转数」是 95~103 / 256 —— 很大。
但这**不是快路径的错**，是 K=8 描述一个自由训练出来的权重本来就只有约 38% 能量
（1.89 已量过）。

所以测试里加了 C2 隔离：快路径与「逐元素展开再乘」比对，
**256 个样本预测翻转必须为 0**。这条把两件事分开了：

- 快路径对不对 → 必须完全一致
- 反编译损失多大 → 可以不好，如实报告

## 接口

```mo
w2c_fit(K)        # 无约束反编译（贪心 OMP，可能选到 O(n²) 基）
w2c_fit_sep(K)    # 1.91 新增：只允许可分离（O(n)）基
caw_mv_ndense(L)  # 该层有多少个基属于 O(n²) 类
```

## 验证

`tests/117_w2cfast.mo`，两处变异均被捕获：

| 变异 | 结果 |
|---|---|
| `w2c_fit_sep` 里 `W2C_SEP = 1` 改成 `0` | 「可分离约束没生效」失败 |
| `caw_mv` 的 CIRC 索引方向写反（`i-p1` → `i+p1`） | C2 隔离翻转 6/256，失败 |

## 踩过的坑

**数据生成的奇偶共振（最阴的一个）**

```mo
h = s * 7919 + 13;
h = h * 1103515245 + 12345;   # 取 h & 1
```

乘数和增量都是奇数，所以在 mod 2 上 `h ← h+1`，**必然逐位交替**。
结果 256 个样本里只有 2 种不同输入，且完全由下标奇偶决定 ——
训练集（偶数下标）的标签清一色为 0，网络学会常数预测器就拿到 128/128。

症状是「精度 128/256 看着像随机猜」，很容易误判成学习率或容量问题。
改成取高位 `((h / 1024) & 1)` 才避开。

**另外两个**：

- 中位数切分的循环上界漏改（256 样本的循环只跑了 256/512），
  于是只有一半样本被标标签，正例数凭空少一半
- `let` 不能写在循环里（1.68 的坑），所以 `w2c_pick` 里的
  部署约束用 `ok` 标志代替 `continue`

## 已知限制

- 只做了矩阵-向量乘，batch 前向的矩阵-矩阵乘未做
- `n ≤ 128`（受 `WR[16384]` 限制），更大规模的加速比是外推而非实测
- 代价模型是乘加次数，不含缓存效应
- 反编译损失（翻转 95/256）对自由训练的权重仍然很大；
  结构化表示真正划算的是**本来就有结构**的权重
