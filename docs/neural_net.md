# 神经网络：在没有浮点的语言里怎么做

墨语言**没有浮点类型**。所以 `lib/nn.mo` 全程用 **Q16.16 定点**。

## 定点表示

```
NN_SCALE = 65536        实数 x 存成 round(x * 65536)
乘法     (a*b + 32768) >> 16
除法     (a * 65536) / b     ← 注意是向零截断，与 Python 的 // 不同
```

选 2^16 而不是 matrix.mo 用的 1000：

1. 移位即除法，还能四舍五入（截断会累积偏差）
2. 精度 1/65536 ≈ 1.5e-5，神经网络够用
3. 值域 ±32768：权重与激活远小于此，乘积最大 4.6e18 < i64 上限

## 没有 exp，怎么做 sigmoid / tanh

用 **Padé 近似**：

```
tanh(x) ≈ x*(27 + x²) / (27 + 9x²)        |x| ≤ 3 内误差 < 1e-3
sigmoid(x) = (1 + tanh(x/2)) / 2
```

**超出 ±3 必须 clamp 到 ±1** —— 这是必要的，不是优化：x=4 时 Padé 算出
1.005，超过 1，继续算下去会发散。

## 这个"看不见但致命"的 bug

第一版反向传播写成**一个循环**：算完 delta[l] 就顺手更新 W[l]。

理由是"算完 delta[l] 后 W[l+1] 就再也不用了"——**这个推理是错的**。
下一轮算 delta[l-1] 时还要用 W[l]，而它已经被改过了。标准反向传播要求
**所有 delta 都用同一份（更新前的）权重**算出。

**最阴的地方：XOR 照样收敛到 4/4，完全看不出异常。**

只有把 Python 定点参考实现（按位复现，包括 C 的向零截断除法与 i64 溢出
回绕）拿来逐轮比对 loss，才把它揪出来：

```
墨语言:  epoch 0 loss 237 / epoch 1 loss 242 / epoch 2 loss 246
参考:    epoch 0 loss 237 / epoch 1 loss 242 / epoch 2 loss 246
```

修正（拆成"算所有 delta"→"统一更新权重"两阶段）后，输出从 985 变成 986
—— 这个细微差异就是改动确实生效的证据。

**教训**：端到端收敛是**必要但不充分**的验证。神经网络这类"差不多就能
工作"的东西，尤其需要一份独立实现的逐位参考。

## 验证方式

`make nntest`（tools/nntest.sh）四道检查：

1. 编译
2. XOR 端到端 4/4
3. **逐轮 loss 与 Python 定点实现比对**（tools/nnref.py）
4. 定点基础：sigmoid(0)≈32768、tanh(1)≈49900、0.5×0.5=16384

## API

```mo
let net: i64 = nn_new(SZ, 3);     # sizes 数组 + 层数
nn_set_act(net, 1, 3);            # 1 层 tanh
nn_set_act(net, 2, 2);            # 2 层 sigmoid
nn_rand_init(net);                # Xavier：U(-1/√n, 1/√n)
let loss: i64 = nn_train(net, &X, &Y, lr);
nn_forward(net, &X);              # 只推理
let p: i64 = nn_out(net, 0);
```

激活编码：0 线性 / 1 ReLU / 2 sigmoid / 3 tanh。

## 已知限制

- **宽度大时可能溢出**：累加多个乘积没有保护，层宽 >1000 需改小 SCALE
- **只有全连接层**，没有卷积
- **只有 SGD**，没有动量 / Adam / 学习率衰减
- 没有正则化、没有 batch
- 权重更新量小于 1/65536 时会**下溢为 0**（定点固有）

## 卷积神经网络（lib/cnn.mo）

架构：`conv → ReLU → pool2 → conv → ReLU → flatten → 全连接`

CNN 与全连接部分靠 `nn_input_grad()` 缝合：它把全连接第一层的 delta
折算成"展平向量的梯度"，CNN 拿它当输出层 delta 往回走。

**conv 后必须接 ReLU**：纯线性卷积堆叠起来仍是线性的，没有非线性
CNN 就退化成一个大线性模型。反向时用 `z > 0` 掩码。

反向顺序同样有讲究：`cnn_conv_dx`（用**更新前**的 W 传梯度）必须在
`cnn_conv_dw`（更新 W）之前 —— 与 nn.mo 里踩过的坑同源。

实测 8×8 四类形状分类，`epoch 400 loss 0`，**8/8 全对**。

### 两个编译器限制迫使 API 变形

1. **参数列表不能换行**（会死循环）
2. **超过 6 个参数 + 函数体内有调用 → 第 7 个起参数错乱**

后者尤其隐蔽：`cnn_set_conv` 原本 8 参数，实测 `h(a)+hh+i` 返回 9
而正确答案是 17。所以卷积核固定 3×3，签名压到 6 参数。

`make cnntest` → `tools/cnntest.sh`：CNN 训练的端到端验证（编译、收敛、8/8 预测正确）。
`make nntest` → `tools/nntest.sh`：全连接网络的验证，含与 Python 定点实现的逐轮 loss 比对。
