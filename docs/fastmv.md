# 结构化快速矩阵-向量乘（1.90）

## 一句话

`y = W·x` 怎么算，**由基函数的类型决定，与振幅无关**。
读一遍类型列表（O(K)）就知道该走哪条路，一个数都不用看。

这是「代码就是权重」的直接推论：既然权重是代码，那么**执行方式也可以从代码静态推导**，
不需要先展开成 n² 个数再去判断它有什么结构。

## 两种做法

**朴素**：把 n² 个元素生成出来（每个 O(K)，共 O(K·n²)），再做 n² 次乘加。

**结构化**：对每个基单独算 `a[k]·(B_k·x)`，而 `B_k·x` 有闭式：

| 基 | B_k·x 的闭式 | 代价 |
|---|---|---|
| `CB_ONE` | `a·Σ_j x[j]` | O(nc) |
| `CB_ALT` | `a·Σ_{j mod 2 = p1} x[j]` | O(nc) |
| `CB_CIRC` | `a·Σ_{j ≡ i-p1 (mod nr)} x[j]` | 全表合计 O(nc) |
| `CB_SYM` | `a·(x[i-p1] + x[i+p1])` | O(nr) |
| `CB_BAND` | `a·Σ_{\|i-j\| ≤ p1} x[j]` | O(nr·(2p1+1)) |
| `CB_LOW` | `a·u_i·(v·x)` | O(nr+nc) |
| `CB_POLY` | `a·(i/nr)^p1·(Σ_j (j/nc)^p2·x[j])` | O(nr+nc) |
| `CB_SIN` | `sin(θi+φj) = sinθi·cosφj + cosθi·sinφj` | O(nr+nc) |
| `CB_CHIRP` | 不可分离 | O(nr·nc) |
| `CB_HASH` | 不可分离 | O(nr·nc) |

九种基里**只有两种是 O(n²)**，其余全是 O(n)。

## 🔴 CIRC 不需要 FFT

循环矩阵乘一般用 FFT 降到 O(n log n)。但在 CaW 表示下不用：

```
c[d] = Σ_{p1_k = d} a[k]
```

`c` 最多只有 **K 个非零元素**（K ≤ 16）。所以循环卷积退化成「K 次移位取数」——
**比 FFT 更快，而且是精确值，没有定点 FFT 的舍入误差**。

这是表示带来的红利：数组表示下 `c` 是稠密的 n 个值，必须用 FFT；
CaW 表示下 `c` 天生稀疏。

## 实测

n = 64，8 个结构化基：

```
朴素    单次 = 631658 ns
快路径  单次 =   7944 ns
加速比 = 79x
```

**加速比随 n 线性增长**（O(n) 对 O(n²) 的特征）：

| n | 朴素 (ns) | 快路径 (ns) | 加速比 |
|---|---|---|---|
| 32 | 163312 | 4054 | 40x |
| 64 | 634075 | 7974 | 79x |
| 128 | 2461352 | 16011 | 153x |
| 256 | 9636514 | 31359 | **307x** |

n 翻倍、加速比翻倍 —— 只测一个 n 看不出这件事，所以测了四个。

## 接口

```mo
caw_mv(L, &x, &y)            # 结构化快速乘
caw_mv_dense(L, &x, &y)      # 朴素参照（校验用）
caw_mv_cost(L)               # 预测代价 —— 只读类型列表，O(K)
caw_mv_cost_dense(L)         # 朴素代价参照
caw_mv_ndense(L)             # 有多少个基属于 O(n²) 类
caw_kind_class(kind)         # 0 = 结构化，1 = 不可分离
```

`caw_mv_cost` 不碰任何数值，纯读类型表 —— 可以在训练前就算出这一层推理要多少次乘加。

## 验证

`tests/116_fastmv.mo`：

1. **九种基逐个比对**快路径与朴素结果，最大差 0~17（相对误差 < 0.3%）
2. 代价模型：预测 1600 vs 朴素 36864
3. 实测加速比，四个规模
4. 含 `CB_CHIRP` 的层必须被判定为「有 O(n²) 基」

**两处变异测试都被捕获**：

| 变异 | 结果 |
|---|---|
| `CIRC` 索引方向写反（`i-p1` → `i+p1`） | 正确性断言失败 2 项 |
| 快路径末尾追加一次 `caw_mv_dense` | 加速比归零，失败 5 项 |

## 精度

快路径与朴素的最大差来自定点与三角函数表的量化：

- 结构化基（CIRC/SYM/BAND/ONE/ALT）：**差 0~2**，基本精确
- 三角类（SIN/LOW/POLY）：差 5~17，来自 sin 表 256 点分辨率
- `CB_SIN` 的可分离分解把「先求和再查表」换成「分别查表再组合」，
  两者都被量化到 1/256 圈，误差约 0.3%

## 已知限制

- `CB_CHIRP` / `CB_HASH` 不可分离，退回 O(nr·nc)
- 只做了矩阵-向量乘，没有做矩阵-矩阵乘（训练中的 batch 前向）
- 三角函数表 256 点，SIN 基的可分离分解引入约 0.3% 误差
- 代价模型是乘加次数，不是真实时钟 —— 缓存、分支预测不计入
