# W2C 训练后管线（1.89）

## 它解决什么

1.87 的 caw 是**正向**：权重由代码生成，训练振幅。
1.88 的 w2c 是**逆向**：给一张已存在的权重，反编译成基函数表示。

但反编译不接进训练管线就只是个分析玩具。本版把三者串成一条链：

```
Phase A   稠密权重训练            → 基线精度
Phase B   权重反编译成代码        → 只留 K 个振幅，测精度
Phase C   只微调振幅              → 看精度能不能回来
Phase D   对照                    → 权重本就在基张成空间时，反编译必须精确
```

示例：`examples/w2cpipe.mo`

## 任务设置

- 教师：固定随机 8 → 12 → 1，标签**按中位数切**（严格 128 正 / 128 负）
- 学生：8 → 16 → 1
- 数据：256 个 8 位模式**全枚举**，偶数号训练 / 奇数号测试（严格不相交）
- 只把 W1（128 个权重）变成代码；W2（16 个）与偏置保持稠密

## 实测结果

```
Phase A   稠密基线        train 117/128   test 107/128   泛化差 10

Phase B   W1 → K 个基（W2 稠密）
   K    残差能量%   压缩    test
   2      92       16x     69
   8      79        4x     69
  16      67        2x     74

Phase C   只微调 K 个振幅（每个 K 都从同一快照重来）
   K    微调前   微调后   压缩   泛化差
   4      69      103      8x     12
   8      69      108      4x      6
  12      70       98      2x     16
  16      74      109      2x      7

Phase D   正交基对照：残差 = 0，基集合原样找回
```

### 三条结论

**1. 自由训练出来的权重没有结构，压不动。**
K=16 时仍只捕获 33% 的能量。这不是反编译器不行——见 Phase D。
基池描述的是循环/对称/带状/傅里叶这类**结构化**模式，而 SGD 收敛到的解是随机的。

**2. 事后近似会毁掉精度，但约束 + 重优化不会。**
直接换成 K 个基的近似，精度从 107 塌到 69；
把权重**约束**到同一个 K 维流形上再只微调振幅，K=8 反而拿到 **108**（高于基线 107）。

差别在于：前者是在拟合一张已经定死的矩阵，后者是在流形里重新找一个好点。

**3. 低维约束是正则化。**
K=8 时泛化差从 10 降到 6，test 精度略高于稠密基线。
把 128 个自由度压到 8 个，过拟合的空间本身就小了。

（K=12 的 98 低于两侧的 108/109 —— 非单调，源于 OMP 贪心选基在不同 K 下选中了不同组合，
不是实现错误，但说明**不能只看 K 大小**，要看实际选中了哪些基。）

## 五个坑

### 1. 反编译必须从权威副本取权重

第一版写 `w2c_from_block(G_W1, ...)`，而进入代码模式后 `build()` 里的 `G_W1`
已经是 CaW **重建出来**的块。于是第二轮起的"残差"是在拟合自己上一轮的重建，
K≥4 残差恒为 0 —— 数字很好看，参照物却被自己覆盖了。

> 症状：完美得可疑的结果。判断标准是"这个数会不会太好了"。

修法：始终从训练时保存的 `DW1` 数组取。

### 2. `w2c_relsq` 的退化假阳性

`relsq` 在 `energy < 1` 时直接返回 0，于是**全零矩阵**也会报"残差 0 = 完美拟合"。
示例代码里 `caw_amp_rand(L1, 3)` 就这样骗过了一次——第二个参数是**定点尺度**，
`3` 表示振幅约 `3/65536 ≈ 0.00005`。

对策：断言前先查 `w2c_energy()`。测试 `tests/115` 里两条都加了能量门槛。

### 3. CaW 层表会耗尽

`CW_MAXL = 16`，而扫描 K=2..16 每次 `w2c_emit()` 都会新开一层，
加上 W2 那层就超了 —— `caw_layer` 返回 -1，而调用方不检查，
结果是精度数字越来越乱，看不出是容量问题。已提到 64。

### 4. 各 K 之间共享偏置会污染对照

偏置是各 K 共享的。K=4 微调完偏置变了，K=8 就白捡一个更好的起点：
同一组权重在 Phase B 是 69、在 Phase C 是 105。
**两个数字对不上就是线索。**

修法：`snap_save()` / `snap_load()`，每个 K 都从同一快照重来。

### 5. 标签倾斜会让"高精度"毫无意义

第一版用 `sigmoid(s+TVB) > 0.5` 定标签，256 个样本里只有 7 个正例，
网络学会"永远猜负类"就拿到 **test 128/128**，而 train 只有 121/128。

> **测试精度高于训练精度就是这个退化的征兆。**

改成按中位数切，强制 50/50。

## 反编译器的能力边界（Phase D 回答的）

| 情况 | 结果 |
|---|---|
| 权重由**正交基**生成（CIRC 不同移位，支撑集不交） | 残差 **0**，基集合原样找回 |
| 权重由**非正交混合基**生成 | 残差 > 0（实测约 7%），贪心 OMP 不保证找回原集合 |
| 自由训练的稠密权重 | 残差 67%~92%，基池里没有能描述它的结构 |

第二条是 OMP 的固有性质，不是 bug：正交时匹配追踪是精确的，非正交时不是。

## 已知限制

- 只压缩了 W1；每层单独决定要不要转代码
- OMP 贪心，不保证最优（最优子集选择是 NP-hard）
- 基池是固定的手写集合，不会自适应地造新基
- 振幅微调用的是普通 SGD，没有针对低维流形调整步长
- 结论基于单个 teacher-student 任务，换任务要重新测

## 为什么这条链有意义

量化（PTQ）压缩后仍是 O(nr·nc) 个数，只是每个变短。
这条链改的是**表示的维度**：128 个权重 → 8 个振幅 + 8 个基函数描述，
而且转换结果**可读**（"这一层 = 0.8 的循环项 + 0.3 的傅里叶项"）。

更实际的一点是：约束到 K 维流形后**还能继续训练**，且精度不掉——
这让"存 K 个数"不只是推理时的省法，也是训练时的省法。
