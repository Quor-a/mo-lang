# Code-as-Weights（1.87）：权重即代码

## 核心思想

传统表示：权重是一个 nr×nc 的数值数组，O(nr·nc) 存储。

本表示：权重是一个**生成函数**

```
W[i][j] = Σ_k  a[k] · B_k(i, j)
```

- `B_k` 是**由代码定义的基函数**（类型 + 参数）
- `a[k]` 是可学习振幅

由此：

| | 数组表示 | 代码表示 |
|---|---|---|
| 存储 | O(nr·nc) | **O(K)** |
| 结构先验 | 隐含在数值里 | **写在基函数类型里** |
| 判断"是否循环矩阵" | 遍历 O(n²) 个元素 | **看类型列表，O(K)** |

## 为什么是线性的

`W` 对 `a[k]` 的偏导就是 `B_k` 本身：

```
∂L/∂a[k] = Σ_ij  ∂L/∂W[i][j] · B_k(i, j)
```

即**梯度与基函数的 Frobenius 内积**。基函数不求导——这是整个设计能成立的关键，
也是它比 hypernetwork 简单得多的原因（hypernetwork 要对生成器求导）。

## 基函数

| 类型 | 含义 | 带来的结构先验 |
|---|---|---|
| `CB_ONE` | 常数 1 | 全局缩放 |
| `CB_POLY` | `(i/nr)^p1·(j/nc)^p2` | 平滑低秩 |
| `CB_CIRC` | `(i-j) mod nr == p1` | **循环 / 平移等变** |
| `CB_SYM` | `\|i-j\| == p1` | **对称** |
| `CB_SIN` | `sin(2π(p1·i/nr + p2·j/nc))` | 傅里叶基 |
| `CB_HASH` | 位混合伪随机 | 高频细节 |
| `CB_BAND` | `\|i-j\| <= p1` | **带状 / 局部连接** |
| `CB_LOW` | `sin(p1·i)·sin(p2·j)` | 低秩外积 |

`sin` 用泰勒级数在初始化时填 65 点表，再按象限对称扩展。实测精度：
`sin(π/2)` = 65527 vs 65536，误差 0.014%。

## 实测

### 训练收敛（XOR）

8 隐层，偏置也由 CaW 生成：

```
参数 20    展开权重 33
总 loss = 35
预测：0.006  0.993  0.984  0.013     （期望 0 1 1 0）✓
```

### 有限差分验证（训练前）

| k | autodiff | 有限差分 | 差 |
|---|---|---|---|
| 0 | 290 | 276 | 14 |
| 5 | 404 | 389 | 15 |
| 6 | -472 | -454 | 18 |
| 7 | -758 | -707 | 51 |

相对误差 < 7%，是定点量化误差，不是梯度错。

> 这一项是**唯一能证明梯度真的对**的手段。训练收敛只能证明"能学"，
> 证明不了梯度方向对——事实上后面会看到，梯度算错时 loss 也可能降。

### 存储

```
16×16 层用 8 个基：参数 8，展开权重 256，压缩 32×
```

### 静态结构分析

```
CIRC(0)+CIRC(1)      → is_circ = 1
SYM+BAND 方阵        → is_sym  = 1
BAND(2)              → bandwidth = 2
混入 CIRC 后         → is_sym  = 0
```

全部 O(K)，不遍历任何权重数值。

## 🔴 本轮最重要的坑：手工 `ad_set` 会切断梯度流

第一版为了给网络加偏置，把输入扩展成 `(x0, x1, 1)`，
再把激活值**手工复制**到新块来拼接常数：

```mo
ax = ad_block(9);
while i < 8 { ad_set(ax + i, ad_val(a + i)); ... }   # ← 断开梯度
ad_set(ax + 8, 65536);
```

症状：

```
grad(W2) = -7955 ...    ← 非零（最后一层正常）
grad(a)  = 0 0 0 ...    ← 全零
grad(h)  = 0 0 0 ...
grad(W1) = 0 0 0 ...
```

`ax` 是一个**没有 tape 边的常量块**，梯度流到它就停了。
于是只有最后一层权重在更新，**loss 不降反升**。

我先后怀疑过：学习率、定点 sigmoid 饱和、容量不足、CaW 梯度公式——
全都不对。**逐级打印梯度**才定位到断点。

修法：偏置用 `ad_vadd` 接进 tape（偏置本身也由 CaW 生成）。

> tape-based AD 里，任何绕过算子的值搬运都会静默断链。
> 判断依据不是"loss 是否下降"，而是**每一级的梯度是否非零**。

## 第二个坑：层 ID 不能假定为 0,1,2,3

`caw_layer()` 返回递增 ID。测试里先建了几个验证用的临时层，
占了 0..2，然后网络写 `caw_basis(0, ...)` 就**配到了临时层上**。

症状：参数统计变成 13（应为 20），网络结构完全错，FD 只有 k=0 非零。

修法：层 ID 一律存变量（`NW1 = caw_layer(...)`）。

## 验证

1. **手工验算**：循环矩阵逐元素对照（含"每行是上一行的循环移位"）
2. **有限差分**：8 个振幅逐个对照，相对误差 < 7%
3. **训练收敛**：XOR 4/4，总 loss 35
4. **静态分析**：is_circ / is_sym / bandwidth 的正反例
5. **变异测试**（两项，均被捕获）：
   - 优化方向反号 → fail 0 → 3
   - CIRC 判定多放行一个偏移 → fail 0 → 3

## 接口

```mo
caw_layer(nr, nc, nk) -> L
caw_basis(L, k, kind, p1, p2)
caw_amp(L, k, v) / caw_getamp(L, k)

caw_gen(L, i, j) -> W[i][j]
caw_block(L) -> s           # 分配 ad 权重块并填充
caw_refill(L, s)            # 重新填充已有块

caw_accum(L, s)             # 反向后：块梯度 → 振幅梯度
caw_step(L, lr)             # SGD
caw_step_mom(L, lr, mo)     # 动量
caw_step_adam(L, lr, b1, b2, eps)

caw_is_circ(L) / caw_is_sym(L) / caw_bandwidth(L)
caw_nparam(L) / caw_nweight(L)
```

## 限制

- **只做了生成与梯度，没有利用结构做快速乘法**。纯 CIRC 组合等价于
  一维卷积，矩阵乘可降到 O(n log n)（FFT），未实现
- 层 ≤ 16，每层基函数 ≤ 16
- 块级粒度，块内稀疏性不参与
- 振幅初始化尺度敏感：定点 sigmoid 饱和区很窄，振幅过大梯度即归零
  （与 1.34「relu 死亡」、1.70「定点饱和」同源）
- 混合基时结构判定退化为"不成立"，只识别纯结构

## 与已有机制的关系

- **autodiff (1.78+)**：CaW 块是普通 ad 权重块，梯度从 tape 反传，不改动编译器
- **ASD (1.80)**：ASD 靠传播索引集推断稀疏模式；CaW 的稀疏模式可以从
  基函数代码**符号解出**，连传播都不需要——这是代码表示独有的优势
- **最优 Jacobian 累积 (1.86)**：CaW 的梯度是线性的，代价模型可精确给出
