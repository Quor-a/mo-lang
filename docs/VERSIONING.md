# 版本号规范（v1.1204 定稿）

## 规则

所有用户可见的版本号一律写作：

    vMAJOR.MINOR.PATCH

例：`v1.1203.0`。

- `v` 前缀：CHANGELOG 标题、Release tag、文档、错误信息中必须带。
- 不带 `v` 的裸数字（`1.1203.0`）仅允许出现在机器可读文件 `VERSION` 与构建脚本参数中。
- 禁止四段式（`1.1196.0.0`）——历史条目已于 v1.1204 全部改正。
- IP 地址（`1.2.3.4`）与语义化依赖版本号（`net.mo` 版本探测串）不属于版本号，不受本规范约束。

## 各处用法

| 位置 | 格式 |
|---|---|
| git tag / Release | `v1.1203.0` |
| CHANGELOG 标题 | `## v1.1203.0` |
| VERSION 文件 | `1.1203.0`（无 v，供脚本 read） |
| build-release.sh 参数 | `1.1203.0`（无 v） |
| 文档/汇报 | `v1.1203.0` |
