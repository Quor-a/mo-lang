# 墨语言新特性总览（v1.971–v1.1054）

本篇补记 CHANGELOG 断层期间及之后落地的语言内核特性。所有特性都有 tests/ 编号用例覆盖。

## 编译期常量表达式（v1.974–v1.1006）

- 顶层与局部 `const` 声明，支持四则、取模、移位、位运算 `& | ^`、逻辑 `&& ||`、比较 `== != < <= > >=`、一元正负号、enum 值、`sizeof`/`alignof`。
- const 可用作：数组长度、case 标签（含 `case A + 1` 后缀折叠、括号表达式）、全局 var 初始化器、component DSL 属性。
- 除零编译期报错；重复定义报错；出错软恢复（消费到 `;` 继续）。

```mo
const MAX: i64 = 100;
const HALF: i64 = MAX / 2;      # 50
let a: [HALF] i64;              # const 作数组长度
```

## 字符串与 switch（v1.1007–v1.1015, v1.1047）

- 字符串六比较 `== != < <= > >=`（字典序）、f-string 表达式插值 `{n + 1}`。
- `switch` 支持字符串判别（逐 case 内容比较）、case 花括号块体、裸 enum 成员作 case。

## 函数指针体系（v1.1016–v1.1021）

- `&fn` 取函数地址；`ptr` 变量/数组元素直接调用 `f(x)`、`t[0](a,b)`；相等比较；作返回值；`[N] ptr` 函数指针表。

## 取地址与类型化指针（v1.1023–v1.1029, v1.1043–v1.1044）

- `&r.x`、`&a[i]`、`&structvar`；`ptr P` / `ptr i64` / `ptr byte` 类型化指针（形参、返回、数组元素全链）。
- ptr 算术保持**字节步**（兼容库生态 `&arr + i*8`）；`p[i]` 索引按元素步；ptr-ptr 为地址差。

## 函数签名增强（v1.1036–v1.1042）

- void 函数（省略 `-> i64`）；形参默认值（尾部连续，>6 个走栈路径）；命名实参 `f(b: 2)`；前向调用支持命名实参与默认值；方法默认/命名实参。

## 聚合类型增强（v1.1030–v1.1035, v1.1045–v1.1055）

- 全局标量/数组可省略初始化（默认 0）；`sizeof`/`alignof` 聚合类型；struct 字段为数组 `v: [N] T`。
- 二维数组 `[N][M] T`（行主布局，局部/全局，i64/byte/ptr/struct 元素）。
- const 数组 `const A: [N] i64 = [...]`（编译期下标）。
- **struct 字面量**：`let p: P = P { x: 1; y: 2; };`、作函数实参 `f(P { ... })`、赋值 `p = P { ... };`、作返回值 `return P { ... };`。字段分号分隔、乱序可、右值为完整表达式。

## 组件 DSL（v1.941–v1.970, v1.1052）

- 编译器原生 `component` 展开：字段类型 text/kv/gauge/bar/spark/pct/delta/hex/num，属性 rows/width/min/max/align/prefix/suffix/fmt/hist/on_click/on_hover/hidden/default/title/sep。
- 带 default 的组件在首次 `_row` 渲染时自动应用默认值（`_init` 自动调用），无需手动 `T_init()`。

## 诊断与告警（v1.971–v1.1005）

- 语法错误软恢复（不再一错即停，elf 仍生成）；`-Wall`：未使用函数/全局变量/const 告警、恒真恒假条件告警。

## v1.1057 – v1.1063（2026-11-03 前后批次）

- **enum 名作类型**（v1.1057）：`let c: Color = BLUE;` —— enum 名在 let/全局 var/形参/返回/数组元素类型位置等价 i64。
- **任意维数组**（v1.1058）：`[2][2][2] i64` 三维及以上，行主布局；二维 struct 元素字段访问同步修复。
- **嵌套 struct 字面量**（v1.1059）：`Q { p: P { x: 3; y: 4; }; n: 5; }`；语句层 `r.f = Q {...}`。
- **struct 值比较**（v1.1060/1063）：`p1 == p2` / `!=` 逐 word 比较；数组值比较同版支持；已知：嵌套字面量在前置比较表达式后有 R_SADDR 污染 bug（待修）。
- **struct 字段默认值**（v1.1061）：`struct P { x: i64 = 10; }` —— let/全局/字面量未列字段取默认。
- **字段整体赋值（变量源）**（v1.1062）：`r.f = q2;` 局部与全局源变量均支持。
- 相关示例：examples/enum_type.mo、ndim_array.mo、struct_eq.mo、field_default.mo。

## v1.1064~1069（2026-11-03）
- **嵌套字面量修复**（v1.1064/1067）：emit_lit_struct R_SADDR=1；字段值 struct 一律整块拷贝（同款存地址 bug 第 2/3 处）。
- **数组元素 struct 字面量赋值**（v1.1065）：`a[0] = P { x: 3; y: 4; };`。
- **任意维嵌套数组字面量**（v1.1066）：`[[1,2],[3,4]]`、三维递归下降；叶子铺平 O_LSTV[64..]（v1.1068 迁移，修复与 dims 表冲突）。
- **len(arr) 内建**（v1.1068）：编译期返回外层元素个数；非数组报错。
- **三元运算符**（v1.1069）：`cond ? a : b` —— 两分支跳转汇合，rax 即选中值；🔴 汇合后 sv(K_LAST,0) 防折叠回退吃跨分支字节；支持嵌套/函数调用分支/括号后接运算。
- 相关示例：examples/len_builtin.mo、ternary.mo。
- **for-in 数组遍历**（v1.1070）：`for x in arr { ... }`（无括号）——编译期发射索引循环；break/continue 支持；二维外层遍历行（行变量是 ptr(标量)，行内 row[i] 按标量步索引）；v1 限制：in 右侧须是数组变量名，N 维内层（对行变量再 for-in）不支持。
- **do-while**（v1.1071）：`do { ... } while (cond);` —— body 至少执行一次；continue 跳条件、break 出循环；支持嵌套。
- **逻辑复合赋值**（v1.1072）：`a &&= b` / `a ||= b` —— 位运算后布尔化（0/1）；词法新增三字符 token &&=、||=。
- **for init 裸赋值**（v1.1072）：`for (i = 0; ...)` / `for (i += 1; ...)`；并修复 v1.1070 引入 for-in 时误删的括号形式 `(` 消费（tests/132 回归）。
- **数组解构**（v1.1073）：`let [x, y, z] = arr;` —— 逐元素拷贝（v1 限一维 i64 数组、RHS 数组变量名）。
- **字符串方法语法**（v1.1074）：非结构体接收者的方法调用回退到库自由函数 —— `s.trim()` → `str_trim(s)`（先查原名，再查 `str_` 前缀，特例 `contains` → `strstr`）；语句与表达式两条方法路径都支持。
- **in 运算符**（v1.1075）：`a in b` = a 是 b 的子串（0/1），parse_eq 层新分支 + g_str_in 朴素子串搜索（O(n·m)，无符号字节比较）。
- **多维行绑定解构**（v1.1076）：`let [r0, r1] = m;` —— 元素为数组/struct 时整块拷贝到栈槽（逐 8 字节），变量持行类型。
- **解构 RHS 行索引**（v1.1077）：`let [a, b, c] = m[1];` —— 常量行索引，索引后类型下降一层。
- **数组整体赋值**（v1.1078）：`q = p;` 同型一维数组块拷贝（g_copy_words）。
- **函数返回数组**（v1.1079）：`fn mk() -> [3] i64`、`return 数组变量;`（rax=地址约定；调用方 `let q: [3] i64 = mk();` 块拷贝。返回局部数组悬垂，建议返回全局/静态数组）。'->' 返回类型链整体提出为独立 fn parse_ret_type（parse_func 嵌套减 1——再加一层 if/else 就会符号作用域错位）。
- **len() 扩展**（v1.1080）：`len(str)`（运行时 strlen，需 import "str.mo"）、`len(多维数组)` = 最外维元素个数。
- **struct 解构**（v1.1081）：`let P { x, y } = r;` —— 字段名按任意顺序逐一 load 到新栈槽（标量字段 load/store；数组/嵌套字段块拷贝）。
- **嵌套解构**（v1.1082）：`let [[x, y], [z, w]] = m;` —— 子元素逐一 load 到新栈槽（子名按列表平铺，meta 记 start/end）。
- **无类型推断 let**（v1.1083）：`let f = add;` —— 省略 `: 类型`，从 RHS 推断（标量/指针/函数地址）；裸函数名可作表达式值。
- **顶层 let**（v1.1084）：`let g: [3] i64 = [1,2,3];` —— 顶层 let 与 var 等价（标量/数组/struct）。
- **二维 for-in 步长修复**（v1.1085）：行 stride 非 2 次幂（如 24）时 for-in 元素寻址由 shl 改 imul —— 此前第二轮 row 从 m[0][2] 起步。
- **for-in 行索引**（v1.1086）：`for v in m[1] { ... }` —— 遍历二维数组的第 i 行（常量行索引，基址 += i*行stride）。
- **数组形参**（v1.1087）：`fn sum(a: [3] i64)` —— 一维数组形参按 ptr(元素) 传入，a[i] 标量步长；长度不随参数传递。
- **推断 let + struct 返回值**（v1.1088）：`let p = mk();` —— struct 函数返回值（rax/rdx 两字寄存器）正确落槽；字面量/struct 变量 RHS（rax=地址）走块拷，由 R_SADDR 区分。
- **解构 RHS 函数调用**（v1.1089）：`let [x, y, z] = mk();` —— 调用结果（rax=数组地址）存隐藏栈槽，元素逐一从槽寻址。同时**硬错化**局部数组返回（悬垂帧），必须返回全局/静态数组。
- **变量行 for-in**（v1.1090）：`for row in m { for v in row {...} }` —— 内层遍历 ptr 行变量，上界取外层 for-in 登记的 `_fl_<深度>` 行长度变量。
- **全局 struct 字面量初始化**（v1.1091）：`var G: P = P { x: 1; y: 2; };` —— 编译期字段值写入数据段（无初始化字段的默认值仍生效）。
- **case 乘除折叠**（v1.1092）：switch case 常量表达式支持 `*` `/`（与 `+` `-` 同级从左到右，enum/const/数字原子均可）。

- **自举性能修复**（v1.1093）：编译 21.8s → 0.13s。根因：探测回滚 set_pos 清 K_CPOS，
  advance_lc 每 token 从头重扫（O(n²)）。新增 set_back 供探测回滚使用；emit4/8 直写。

- **指针字段与链表**（v1.1094）：struct 字段可为 `ptr T`（自引用）；链式访问
  `p.next.v` 中间 ptr 段自动解引用；try_parse_type 支持嵌套数组 `[[N] T]`。

- **range for**（v1.1095）：`for i in 0..10`，端点为编译期常量（数字/const/enum 成员），
  糖展开为 i=A; while i<B; i++。`..` 为新增词法 token。

- **局部数组返回**（v1.1096）：return 局部数组不再硬错——内容拷入数据段隐藏缓冲
  （8KB），返回缓冲地址。调用方需立即消费；连续两次调用后者覆盖前者。

- **数组字面量运行期元素**（v1.1097）：`[n, n+1, -n, GREEN*10]` —— 非常量元素
  运行期求值直接写入目标槽，可与常量元素混用；byte 数组逐字节。

- **match 表达式**（v1.1098）：`match e { PAT => { ... } _ => { ... } }`，
  模式 = 数字/const/enum 成员（可带算术后缀），`_` default，臂隐式 break，
  无穿透。比较链发射。
- **架构决策（v1.1098 评估）**：完整 IR/线性扫描寄存器分配经评估**不采纳**——
  自举已 0.13s（编译速度收益不存在）、产物代码 fib(32) 18ms 已达 -O0 水平
  （代码质量收益 ≈2-4×，不值 101 个 g_ 原语的 emit 主路径重写风险）。
  TLS 对静态单线程目标无意义，搁置。

- **match 增强**（v1.1099）：字符串模式（全字符串臂，g_str_eq 链）+
  守卫 `PAT if cond =>`（失败顺序尝试下一臂，守卫臂豁免 duplicate 检查）。

- **match 表达式**（v1.1100）：`let r = match c { PAT => EXPR, _ => EXPR };`
  与赋值右值。臂值 = 裸表达式（逗号分隔）或 `{ expr }`。结果存变量槽后读回。

### v1.1101.0 match 表达式内嵌 + let 撞槽修复
- `match` 可出现在任意表达式位置（return f() + match …、嵌套等）。
- 修复：推断 let 与 typed let 混用撞槽（v1.1083 起既有 bug）。
- 限制：match 表达式的字符串模式未支持（语句版支持）；臂值表达式臂需逗号分隔。

### v1.1102.0 match 表达式字符串模式 + SWSTR 残留修复
- match 表达式（任意位置）现支持字符串模式，与语句版语义一致。
- 修复 mt_scan 数字模式不清 SWSTR 的跨函数残留（SIGSEGV）。
- let 右值 match 特判统一收敛到 parse_expr/primary 单一入口。

### v1.1103.0 match struct 模式
- `match r { P { x: 1; y: 2; } => …, _ => … }`：字段常量模式，部分匹配可。
- 限制：暂不支持字段绑定变量（捕获）；仅语句版（表达式版同链可后续移植）。

### v1.1104.0 match struct 模式字段绑定
- `P { y: v; }`：字段值标识符 → 绑定变量（i64），臂内可用。
- 常量模式与绑定混用可：`P { x: 3; y: w; }`。

### v1.1105.0 match struct 模式（表达式版）
- `let t = match r { P { y: v; } => v * 2, _ => 111 };` —— struct 模式
  在任意表达式位置可用（含绑定变量）。
### v1.1106.0 match 嵌套 struct 模式
- 模式字段值可为嵌套 struct 字面量/模式，任意组合一层。

### v1.1107.0 match 表达式守卫绑定
- `PAT if cond =>` 在表达式版可用；绑定变量在守卫条件内可引用。

### v1.1108.0 match 语句版守卫绑定
- 语句版 `PAT if cond =>` 守卫 + 绑定变量（臂内可读写绑定）。

### v1.1109.0 match 任意深度嵌套 struct 模式
- 多层嵌套（深度 ≤8）：`P { in: Q { v: n; }; }`，两版（语句/表达式）均支持。

### v1.1110.0 前向 struct 类型
- 签名处（形参/返回/ptr 目标/let/全局 var）可用未定义 struct 名，定义处自动复用。
- 限制（单遍编译）：字段访问/字面量构造仍须在 struct 定义之后。

### v1.1111.0 struct 按值返回修复
- `fn f(x: T) -> T { return x; }`：形参是引用（调用方地址），return 现在先解引用
  再按 rax/rdx 拷贝 —— struct 形参直返不再返回野地址。

### v1.1112.0 const fn（编译期折叠）
- `const fn sq(x: i64) -> i64 { return x * x; }`：调用点 `sq(4)` 编译期求值为 16，
  发射 movabs 立即数，零运行时开销。
- 支持：单参数、体为 `return <算术表达式>;`（字面量/参数/`+ - * / %`/括号/一元负）、
  const fn 调用 const fn（递归折叠，如 `cube(x) = x * sq(x)`）。
- 限制：不支持分支/循环/多语句、不支持 f64。

### v1.1113.0 常量右值折叠扩展（sub）+ shl/sar xchg
- `x - 7` 等右值为常量的减法折叠为 `sub rax,imm`（原 pop+sub+mov 三条 → 二条）。
- `<<` / `>>` 的寄存器交换 3 mov → xchg（6B/2条）。
- 基准：混合运算循环 -27%。>2^31-1 常量自动回退。

### v1.1114.0 shl/sar 常量移位量折叠
- `x << 4`、`y >> 3` 等常量移位折叠为 imm8 单指令（pop+shl 二条）。
- >63 回退 movabs+cl（CPU mask 63 语义不变）。+ - * / % 位运算移位全部支持常量右值折叠。

### v1.1116.0 语句级 enum 声明
- 函数体内 `enum Color { RED; GREEN = 2; }`：自动编号/显式值/const 值全支持，
  分号结尾可选。常量注册进全局 enum 表（作用域上函数退出后仍可见，
  重名先注册者生效——与 top-level 一致）。

### v1.1116 — 语句级 enum 声明
函数体内可直接声明 enum（`enum Color { RED; GREEN = 2; BLUE; }`），复用 top-level 机制：常量注册进全局 enum 表（重名先注册者生效），支持自动编号 / 显式值 / const 成员值，可与 match 组合。

### v1.1117 — 自举验证诚实化（工程）
verify_bootstrap.sh 重写为两层验证：seed（Stage0 语言子集）冒烟 + moc 三级自举链字节一致。Makefile `$(MOC)` 双路径（moc 自举优先 / seed 兜底），消除拼接 mtime 触发的 seed 重编复发债。freshbuild 全新环境 3/3（seed 从零汇编 + 降级自洽）。
