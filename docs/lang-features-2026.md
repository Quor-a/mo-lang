# 墨语言新特性总览（v1.971–v1.1054）

本篇补记 CHANGELOG 断层期间及之后落地的语言内核特性。所有特性都有 tests/ 编号用例覆盖。

## 编译期常量表达式（v1.974–v1.1006）

- 顶层与局部 `const` 声明，支持四则、取模、移位、位运算 `& | ^`、逻辑 `&& ||`、比较 `== != < <= > >=`、一元正负号、enum 值、`sizeof`/`alignof`。
- const 可用作：数组长度、case 标签（含 `case A + 1` 后缀折叠、括号表达式）、全局 var 初始化器、component DSL 属性。
- 除零编译期报错；重复定义报错；出错软恢复（消费到 `;` 继续）。

```mo
const MAX: i64 = 100;
const HALF: i64 = MAX / 2;      # 50
let a: [HALF] i64;              # const 作数组长度
```

## 字符串与 switch（v1.1007–v1.1015, v1.1047）

- 字符串六比较 `== != < <= > >=`（字典序）、f-string 表达式插值 `{n + 1}`。
- `switch` 支持字符串判别（逐 case 内容比较）、case 花括号块体、裸 enum 成员作 case。

## 函数指针体系（v1.1016–v1.1021）

- `&fn` 取函数地址；`ptr` 变量/数组元素直接调用 `f(x)`、`t[0](a,b)`；相等比较；作返回值；`[N] ptr` 函数指针表。

## 取地址与类型化指针（v1.1023–v1.1029, v1.1043–v1.1044）

- `&r.x`、`&a[i]`、`&structvar`；`ptr P` / `ptr i64` / `ptr byte` 类型化指针（形参、返回、数组元素全链）。
- ptr 算术保持**字节步**（兼容库生态 `&arr + i*8`）；`p[i]` 索引按元素步；ptr-ptr 为地址差。

## 函数签名增强（v1.1036–v1.1042）

- void 函数（省略 `-> i64`）；形参默认值（尾部连续，>6 个走栈路径）；命名实参 `f(b: 2)`；前向调用支持命名实参与默认值；方法默认/命名实参。

## 聚合类型增强（v1.1030–v1.1035, v1.1045–v1.1055）

- 全局标量/数组可省略初始化（默认 0）；`sizeof`/`alignof` 聚合类型；struct 字段为数组 `v: [N] T`。
- 二维数组 `[N][M] T`（行主布局，局部/全局，i64/byte/ptr/struct 元素）。
- const 数组 `const A: [N] i64 = [...]`（编译期下标）。
- **struct 字面量**：`let p: P = P { x: 1; y: 2; };`、作函数实参 `f(P { ... })`、赋值 `p = P { ... };`、作返回值 `return P { ... };`。字段分号分隔、乱序可、右值为完整表达式。

## 组件 DSL（v1.941–v1.970, v1.1052）

- 编译器原生 `component` 展开：字段类型 text/kv/gauge/bar/spark/pct/delta/hex/num，属性 rows/width/min/max/align/prefix/suffix/fmt/hist/on_click/on_hover/hidden/default/title/sep。
- 带 default 的组件在首次 `_row` 渲染时自动应用默认值（`_init` 自动调用），无需手动 `T_init()`。

## 诊断与告警（v1.971–v1.1005）

- 语法错误软恢复（不再一错即停，elf 仍生成）；`-Wall`：未使用函数/全局变量/const 告警、恒真恒假条件告警。

## v1.1057 – v1.1063（2026-11-03 前后批次）

- **enum 名作类型**（v1.1057）：`let c: Color = BLUE;` —— enum 名在 let/全局 var/形参/返回/数组元素类型位置等价 i64。
- **任意维数组**（v1.1058）：`[2][2][2] i64` 三维及以上，行主布局；二维 struct 元素字段访问同步修复。
- **嵌套 struct 字面量**（v1.1059）：`Q { p: P { x: 3; y: 4; }; n: 5; }`；语句层 `r.f = Q {...}`。
- **struct 值比较**（v1.1060/1063）：`p1 == p2` / `!=` 逐 word 比较；数组值比较同版支持；已知：嵌套字面量在前置比较表达式后有 R_SADDR 污染 bug（待修）。
- **struct 字段默认值**（v1.1061）：`struct P { x: i64 = 10; }` —— let/全局/字面量未列字段取默认。
- **字段整体赋值（变量源）**（v1.1062）：`r.f = q2;` 局部与全局源变量均支持。
- 相关示例：examples/enum_type.mo、ndim_array.mo、struct_eq.mo、field_default.mo。

## v1.1064~1069（2026-11-03）
- **嵌套字面量修复**（v1.1064/1067）：emit_lit_struct R_SADDR=1；字段值 struct 一律整块拷贝（同款存地址 bug 第 2/3 处）。
- **数组元素 struct 字面量赋值**（v1.1065）：`a[0] = P { x: 3; y: 4; };`。
- **任意维嵌套数组字面量**（v1.1066）：`[[1,2],[3,4]]`、三维递归下降；叶子铺平 O_LSTV[64..]（v1.1068 迁移，修复与 dims 表冲突）。
- **len(arr) 内建**（v1.1068）：编译期返回外层元素个数；非数组报错。
- **三元运算符**（v1.1069）：`cond ? a : b` —— 两分支跳转汇合，rax 即选中值；🔴 汇合后 sv(K_LAST,0) 防折叠回退吃跨分支字节；支持嵌套/函数调用分支/括号后接运算。
- 相关示例：examples/len_builtin.mo、ternary.mo。
- **for-in 数组遍历**（v1.1070）：`for x in arr { ... }`（无括号）——编译期发射索引循环；break/continue 支持；二维外层遍历行（行变量是 ptr(标量)，行内 row[i] 按标量步索引）；v1 限制：in 右侧须是数组变量名，N 维内层（对行变量再 for-in）不支持。
- **do-while**（v1.1071）：`do { ... } while (cond);` —— body 至少执行一次；continue 跳条件、break 出循环；支持嵌套。
- **逻辑复合赋值**（v1.1072）：`a &&= b` / `a ||= b` —— 位运算后布尔化（0/1）；词法新增三字符 token &&=、||=。
- **for init 裸赋值**（v1.1072）：`for (i = 0; ...)` / `for (i += 1; ...)`；并修复 v1.1070 引入 for-in 时误删的括号形式 `(` 消费（tests/132 回归）。
- **数组解构**（v1.1073）：`let [x, y, z] = arr;` —— 逐元素拷贝（v1 限一维 i64 数组、RHS 数组变量名）。
- **字符串方法语法**（v1.1074）：非结构体接收者的方法调用回退到库自由函数 —— `s.trim()` → `str_trim(s)`（先查原名，再查 `str_` 前缀，特例 `contains` → `strstr`）；语句与表达式两条方法路径都支持。
- **in 运算符**（v1.1075）：`a in b` = a 是 b 的子串（0/1），parse_eq 层新分支 + g_str_in 朴素子串搜索（O(n·m)，无符号字节比较）。
- **多维行绑定解构**（v1.1076）：`let [r0, r1] = m;` —— 元素为数组/struct 时整块拷贝到栈槽（逐 8 字节），变量持行类型。
