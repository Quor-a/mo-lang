# W2C —— 把真实权重反编译成代码（1.88）

## 这是 caw 的另一半

| | caw.mo（1.87） | w2c.mo（1.88） |
|---|---|---|
| 方向 | 正向：代码 → 权重 | **逆向：权重 → 代码** |
| 训练对象 | 振幅 a | —（给定 W 直接求解） |
| 产物 | `W = Σ a_k·B_k` | `{ (kind_k,p1_k,p2_k), a_k }` |

同一套基函数，两个方向，接成一个环。

## 算法：OMP + 正规方程

基函数之间**不正交**，所以不能逐个独立投影。每轮挑一个使残差下降最多的基，
然后**重解全部振幅**。正规方程：

```
G[k][l] = ⟨B_k, B_l⟩ = Σ_ij B_k(i,j)·B_l(i,j)
b[k]    = ⟨W,   B_k⟩ = Σ_ij W(i,j)·B_k(i,j)
G·a = b
```

**基函数不求导** —— 与 caw.mo 正向一致，是同一条性质的两面。

## 🔴 坑 1：OMP 选择准则写错，会系统性偏好"小范数"的基

正确准则是最大化残差下降量 `|<R,b>|² / ‖b‖²`。
第一版写成 `|<R,b>| / ‖b‖²`（振幅估计），于是**范数小的基被过度偏好**：

- 循环基 ‖b‖² ≈ 16<<16（只有 16 个非零元素）
- 傅里叶基 ‖b‖² ≈ 128<<16（全部 256 个元素非零）

差 8 倍，结果真实正弦权重一次傅里叶基都没选上。
修正后 K=1 残差从 88% 降到 52%，K=16 从 56% 降到 41%。

## 🔴 坑 2：岭正则会让已知结构的反编译不再精确

加了 `G[k][k] += 0.0625` 的正则后，`W = 2.0·CIRC(1) + 0.5·SYM(0)`
解出来是 1.9929 / 0.4980，误差 511 —— 不报错，只是不再精确。

改为**不加正则**，线性相关的基由 `w2c_solve` 检出后回退重选。
（CIRC(0) 与 SYM(0) 在方阵上是同一个矩阵，必然遇到线性相关。）

## 🔴 坑 3：变量重名

`W2C_NC` 同时被用作**列数**和**候选池大小**。建池后列数变成池大小，
于是所有基函数求值都用错误的列数 —— 不崩溃，只是结果全错。
候选池大小改名为 `W2C_NP`。

## 真实权重实验：Transformer 正弦位置编码

`PE(pos,2i)=sin(pos/10000^(2i/d))`，取自 Vaswani et al. 2017，
是原始 Transformer / 早期 GPT、BERT 系模型里**真实存在**的一张权重
（注册为 buffer，非可学习参数），公式公开确定。d=16, pos=0..15。

| K | 残差能量比 | 压缩比 |
|---|---|---|
| 1 | 52% | 64× |
| 2 | 46% | 32× |
| 4 | 45% | 16× |
| 8 | 43% | 8× |
| 16 | **41%** | 4× |

**41% 不是失败，是诊断信号。** 残差按列统计：

```
列 0-3（高频维度）残差 = 2305676
列 12-15（低频维度）残差 = 320330      ← 差 7.2×
```

残差集中在高频维度，因为现有基库都是**可分离**的
（`CB_SIN`/`CB_LOW` 都是 `f(i)·g(j)` 形式），而真实 PE 的**频率沿维度指数衰减**，
不可分离。为此新增了两个基：

- `CB_CHIRP` —— 频率随列线性增长
- `CB_ALT` —— 列交替条纹（真实 PE 的 sin/cos 在维度上交替）

加上 `CB_ALT` 后残差从 53% 降到 41%。**迭代方式就是：看残差集中在哪，补哪类基。**

## 闭环

反编译结果落成 caw 层，用**正向**生成器 `caw_gen` 重建，
与反编译器自己的重建值逐值比较，最大差 = 0。两条独立实现互相印证。

## 已知结构验证

`W = 2.0·CIRC(1) + 0.5·SYM(0)` 反编译 → 振幅精确为 131072 / 32768（即 2.0 / 0.5），
**残差 = 0**。

## 限制

- 矩阵 ≤ 32×32，基 ≤ 16
- 候选池 ~200 个，OMP 是贪心，不保证全局最优
- 只做稠密矩阵反编译，不利用块内稀疏性
